## Tentang LeafOrLeave

LeafOrLeave adalah browser modern untuk macOS yang dikembangkan secara native menggunakan SwiftUI dan WebKit.

LeafOrLeave tidak dibuat untuk menjadi browser dengan fitur sebanyak mungkin. Proyek ini berfokus pada pengalaman menjelajah yang terasa alami di macOS, lebih terorganisasi, dan tidak dipenuhi gangguan yang tidak diperlukan.

LeafOrLeave memandang browser bukan hanya sebagai tempat untuk membuka halaman web, tetapi sebagai ruang kerja digital tempat pengguna mengelola berbagai aktivitas, proyek, dan konteks dalam satu aplikasi.

Workspace menjadi bagian utama dari pengalaman LeafOrLeave. Setiap workspace dapat digunakan sebagai lingkungan yang terpisah untuk kuliah, pengembangan perangkat lunak, penelitian, hiburan, maupun aktivitas lainnya.

Dengan pendekatan tersebut, pengguna dapat berpindah dari satu konteks ke konteks lain tanpa harus mencampurkan seluruh tab di dalam satu ruang kerja yang penuh.

⸻

## Filosofi Nama

Nama LeafOrLeave berasal dari dua kata yang terdengar serupa, tetapi memiliki makna yang berbeda.

**Leaf** berarti daun. Kata ini menggambarkan pertumbuhan, pengetahuan, halaman, ide, dan sesuatu yang terus berkembang.

**Leave** berarti pergi atau meninggalkan. Kata ini menggambarkan keputusan untuk menutup gangguan, melepaskan sesuatu yang tidak lagi diperlukan, dan melanjutkan pekerjaan yang lebih penting.

Setiap halaman yang dibuka di internet merupakan sebuah pilihan.

Pengguna dapat tetap berada di dalamnya, mempelajari sesuatu, dan membiarkan gagasan baru tumbuh.

Namun, pengguna juga dapat meninggalkannya ketika halaman tersebut tidak lagi memberi nilai.

LeafOrLeave dibangun berdasarkan gagasan sederhana:

> **Setiap tab adalah pilihan. Pertahankan yang penting dan tinggalkan yang tidak.**

⸻

## LeafOrLeave sebagai Ruang Kerja

LeafOrLeave bukan hanya browser yang memiliki fitur workspace.

LeafOrLeave adalah ruang kerja digital yang menggunakan browser sebagai bagian utama dari alur kerja pengguna.

Setiap workspace dapat dianggap sebagai sebuah ruangan tersendiri.

Sebagai contoh:

* Workspace kuliah menyimpan LMS, materi, jurnal, dan halaman pencarian.
* Workspace pengembangan menyimpan GitHub, dokumentasi, localhost, dan alat pengembangan.
* Workspace hiburan menyimpan YouTube, musik, dan halaman lain yang sedang dinikmati.
* Workspace penelitian menyimpan sumber, artikel, referensi, dan catatan yang saling berkaitan.

Dengan memisahkan setiap aktivitas ke dalam workspace yang berbeda, pengguna tidak perlu menghadapi satu jendela yang dipenuhi tab dari berbagai konteks.

Berpindah workspace seharusnya terasa seperti berpindah ruangan, bukan seperti membersihkan meja yang penuh.

## Pengalaman Aplikasi

### Navigasi dan Tab

- Toolbar native dengan kolom alamat, pelengkapan otomatis berdasarkan riwayat/frekuensi kunjungan, kontrol navigasi, status jaringan, serta aktivitas unduhan.
- Tab bar dengan favicon, status pemuatan, indikator audio, target tombol tutup yang konsisten, dan pencarian tab.
- Judul tab terpusat dengan lebar responsif; tab mengecil otomatis lalu beralih ke horizontal scroll.
- Seret tab memakai payload internal aplikasi sehingga tidak membuat file UUID di Desktop dan tidak menciptakan tab baru secara berulang.
- Tab dapat dipindahkan ke jendela baru, dikembalikan ke jendela asal, atau dipindahkan antar-jendela tanpa memuat ulang `WKWebView`.
- Jendela sumber yang sudah kosong ditutup otomatis setelah perpindahan benar-benar selesai.
- Mode split menampilkan hingga tiga tab dalam satu jendela; toolbar mengikuti panel yang sedang fokus.
- Dukungan popup, jendela autentikasi, file lokal, zoom, hard reload, dan navigasi keyboard.
- Halaman Tab Baru dengan tautan cepat, aktivitas terbaru, serta identitas workspace aktif.
- Tab Privat memakai penyimpanan sementara WebKit, tidak menulis History, dan tidak masuk pemulihan sesi.
- Keyboard shortcut utama dapat direkam ulang oleh pengguna; konflik ditukar otomatis.
- Kegagalan website dan kondisi offline memiliki halaman status khusus dengan aksi coba lagi dan kembali.

### Workspaces

- Workspace bawaan untuk Study, Coding, dan Media.
- Workspace khusus dengan nama, simbol, warna aksen, dan halaman awal.
- Tab benar-benar dipetakan dan dipertahankan per workspace.
- Selected tab dan pinned tab disimpan secara independen.
- Workspace editor untuk membuat, mengubah, mengurutkan, dan menghapus workspace.

### Passwords dan Website Sessions

- Credential disimpan di macOS Keychain.
- Brankas kata sandi dibuka menggunakan Touch ID atau kata sandi Mac.
- Dukungan melihat, menyalin, mengubah, memperbarui, dan menghapus kredensial.
- Kata sandi yang disalin dibersihkan otomatis dari papan klip setelah 60 detik.
- Pengisian otomatis mendukung beberapa akun dan alur login bertahap.
- Kata sandi saat ini, kata sandi baru, dan kode verifikasi ditangani secara terpisah.
- Tawaran Simpan/Perbarui ditampilkan setelah terdapat indikasi login berhasil.
- Data website menggunakan penyimpanan persisten agar sesi dapat bertahan setelah aplikasi ditutup.

### Performance

- Lifecycle tab: `active`, `background`, `sleeping`, `frozen`, dan `discarded`.
- Smart suspension berdasarkan batas waktu tidak aktif, tingkat agresivitas, dan tekanan memori.
- Playing media, mini-player, pinned tab, download, upload, serta protected tab dapat dikecualikan.
- Panel performa menampilkan status tab dan hasil evaluasi terakhir.
- Tombol **Optimize Now** tersedia untuk optimasi manual.

### Network dan Exam Protection

- Pemantauan konektivitas menggunakan `Network.framework`.
- Pengukuran latensi dan status jaringan langsung pada toolbar/sidebar.
- Resolusi alamat perangkat lokal dan fallback koneksi khusus jaringan lokal.
- Halaman offline dan overlay pemulihan membantu menjaga konteks ketika koneksi terputus.
- Kegagalan DNS, timeout, koneksi ditolak, sertifikat, dan navigasi umum diterjemahkan menjadi pesan yang mudah dipahami.
- Protected tab mendapatkan konfirmasi sebelum ditutup atau aplikasi dihentikan.
- Snapshot formulir hanya menangani kolom aman dan tidak merekam kata sandi, kolom tersembunyi, file, atau data pembayaran.

> [!IMPORTANT]
> Exam Protection tidak dapat memperpanjang timeout server, menjamin jawaban tersimpan, atau menggantikan autosave milik website. Gunakan backup dan ikuti prosedur resmi platform yang digunakan.

### Media dan Downloads

- Status audio/video diperbarui per tab.
- Kontrol play, pause, mute, seek, dan mini-player.
- Equalizer eksperimental untuk media HTML5 yang kompatibel.
- Panel Downloads modern dengan ringkasan aktif/selesai/ukuran, pencarian, filter, status, dan aksi kontekstual.
- Notifikasi unduhan, progres toolbar, riwayat unduhan, dan pemilih tujuan.
- File dapat dibuka langsung atau ditampilkan di Finder.

### Settings dan Personalisasi

- Settings dengan navigasi terstruktur dan pencarian.
- Pengaturan General, Tabs, Workspaces, Performance, Network, Exam Protection, Media, Privacy, Appearance, Developer, dan Advanced.
- Mode terang atau gelap diterapkan konsisten ke seluruh jendela, toolbar, panel, pustaka, dan halaman internal aplikasi.
- Pratinjau tema, warna aksen, kerapatan antarmuka, gaya animasi, dan penyesuaian toolbar.
- Editor tautan cepat untuk halaman Tab Baru.
- Pemilih ikon yang dapat dicari dengan katalog luas untuk workspace dan quick links.
- Editor shortcut keyboard untuk tab, jendela, navigasi, sidebar, pencarian, dan split screen.
- Metrik diagnostik dapat dinonaktifkan dan dibersihkan dari memori.

### Library

- Bookmarks dan History menggunakan tata letak modern yang konsisten dengan Downloads.
- Pencarian, pengelompokan, metadata, status kosong, dan aksi item dibuat lebih jelas dan responsif.
- Panel Bookmarks, History, dan Downloads dipersiapkan saat aplikasi aktif sehingga dapat terbuka pada interaksi pertama tanpa jeda yang terasa.

## Privasi dan Keamanan

LeafOrLeave memisahkan kredensial, sesi website, dan diagnostik:

- Kata sandi hanya disimpan pada macOS Keychain.
- Pembukaan vault memerlukan autentikasi pemilik perangkat.
- Kata sandi tidak ditulis ke Settings atau laporan diagnostik.
- Log operasional tidak menyertakan URL, cookie, isi formulir, kredensial, atau token autentikasi.
- Buffer peristiwa diagnostik dibatasi untuk mencegah pertumbuhan memori tanpa batas.
- Tab Privat tidak menyimpan riwayat, cookie, cache, penyimpanan lokal, atau alamat sesi pemulihan.
- App Sandbox dan akses jaringan keluar dideklarasikan secara eksplisit.
- Kamera, mikrofon, lokasi, Bluetooth, kontak, kalender, foto, input suara, screen sharing, serta jaringan lokal memiliki deskripsi izin yang jelas.
- Desktop, Documents, Downloads, volume eksternal, volume jaringan, file pilihan pengguna, pencetakan, dan penyimpanan unduhan memakai izin sistem yang sesuai.
- Izin sensitif tetap berada di bawah kontrol macOS dan hanya digunakan setelah pengguna atau website yang relevan memintanya.

Jangan membuka laporan masalah publik yang mengandung kata sandi, token, jawaban ujian, cookie, atau data pribadi.

## Menjalankan Proyek

1. Clone repository:

   ```bash
   git clone https://github.com/Bapakardhie93/LeaforLeave.git
   cd LeaforLeave
   ```

2. Buka `LeafOrLeave.xcodeproj`.
3. Pilih scheme **LeafOrLeave** dan destination **My Mac**.
4. Pilih Signing Team milik Anda.
5. Jalankan aplikasi menggunakan `⌘R`.

Build tanpa penandatanganan kode:

```bash
xcodebuild \
  -project LeafOrLeave.xcodeproj \
  -scheme LeafOrLeave \
  -configuration Debug \
  -destination 'platform=macOS' \
  build CODE_SIGNING_ALLOWED=NO
```

Menjalankan unit test:

```bash
xcodebuild test \
  -project LeafOrLeave.xcodeproj \
  -scheme LeafOrLeave \
  -destination 'platform=macOS' \
  -only-testing:LeafOrLeaveTests
```

Menjalankan UI test utama:

```bash
xcodebuild test \
  -project LeafOrLeave.xcodeproj \
  -scheme LeafOrLeave \
  -destination 'platform=macOS' \
  -only-testing:LeafOrLeaveUITests/LeafOrLeaveUITests/testModernSettingsNavigation \
  -only-testing:LeafOrLeaveUITests/LeafOrLeaveUITests/testLibraryPanelsOpenOnFirstClick
```
