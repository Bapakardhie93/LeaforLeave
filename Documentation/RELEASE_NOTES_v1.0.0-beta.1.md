# LeafOrLeave v1.0.0-beta.1

Beta publik pertama LeafOrLeave, browser native macOS yang berfokus pada workspace, pengelolaan tab, dan pengalaman browsing yang tenang.

## Sorotan

- Menambahkan alur **Keep, Archive, atau Leave** untuk membantu meninjau dan merapikan tab tanpa kehilangan halaman penting.
- Menambahkan **Review Open Tabs** serta Archive yang menyimpan judul, URL, waktu, dan konteks workspace.
- Menambahkan ekspor dan impor backup JSON berversi untuk settings, template workspace, bookmark, dan archive.
- Memperbarui toolbar, sidebar, Settings, Downloads, History, dan Bookmarks agar lebih konsisten dan mudah dipindai.
- Menambahkan tampilan **Liquid Glass** dengan lapisan yang lebih pekat agar teks dan kontrol tetap terbaca di atas wallpaper.
- Memperbaiki drag-and-drop tab, perpindahan antar-jendela, pemulihan sesi, status tab latar belakang, serta stabilitas WebKit.
- Menambahkan pipeline CI dan pemeriksaan rilis lokal untuk build serta pengujian otomatis.

## Perubahan fitur

- Fitur **Equalizer dihapus** dari beta ini. Kontrol media utama seperti play/pause, mute, seek, dan mini-player tetap tersedia.

## Kompatibilitas

- Membutuhkan macOS 14 atau lebih baru.
- Paket universal mendukung Mac Apple Silicon dan Intel.
- Ini adalah build beta bertanda tangan pengembangan dan belum dinotarialisasi untuk distribusi publik. macOS dapat menampilkan peringatan saat aplikasi pertama kali dibuka; gunakan klik kanan **Open** jika Anda mempercayai file yang diunduh.

## Catatan beta

Gunakan beta ini untuk pengujian. Sebelum memperbarui, ekspor backup dari menu **File > Export Browser Data…**. Password, cookie, history, dan sesi tab aktif tidak disertakan dalam backup.
